고객에 연결한 기록은 자비아 「내 고객 → 고객 상세」에서도 보여요.

고객 연락처는 AI에 전달되지 않습니다(가린 번호만). 알림톡은 지금처럼 건당 20원이 포인트에서 차감됩니다. 계산은 자비아 계산기로만 하고, AI가 스스로 계산한 값은 「참고용 추정」으로 표시합니다.

질문을 누르면 Claude가 질문이 채워진 채로 열려요. 고객 이름·금액만 바꿔서 보내세요.

이용 가이드 — 아주 쉽게

처음이시면 1번부터 차례로 펼쳐 보세요.

1. MyJai 가 뭔가요?

MyJai 는 자비아를 잘 아는 회원님 전용 비서입니다. 회원님이 쓰는 AI 앱(Claude 등)에 자비아를 연결해 두면, AI 에게 말로 부탁한 일을 자비아에서 대신 찾아보고·정리하고·보내 줍니다.

예를 들어 오늘 브리핑 해줘 라고 하면 오늘 할 일·새 고객 요청·생일·만기 고객을 모아 알려 주고, 이영희 고객 연금 상담한 내용 업무일지에 적어줘 라고 하면 업무일지에 기록해 줍니다.

자비아 화면을 일일이 열지 않아도 되고, 휴대폰에서는 음성으로도 됩니다.

2. 준비물 — Claude 앱과 PC 한 번
  1. Claude 가입: claude.ai 에서 구글 계정 등으로 무료 가입합니다.
  2. 휴대폰 앱: 앱스토어·플레이스토어에서 「Claude」를 설치하고 같은 계정으로 로그인합니다.
  3. PC 에서 한 번 연결: 연결은 PC 의 Claude(웹 claude.ai 또는 PC 앱)에서 한 번만 하면 됩니다. 그 뒤로는 휴대폰 앱에서도 저절로 쓸 수 있습니다.

무료 플랜으로도 연결할 수 있지만(직접 추가하는 커넥터 1개까지) 하루 사용량이 적어 체험용입니다. 매일 업무에 쓰시려면 개인 유료 요금제(Claude Pro 등)를 권합니다.

3-1. 연결하기 — PC 에서 4단계
  1. PC 에서 claude.ai 에 로그인 → 왼쪽 메뉴 사용자 지정(Customize) → 커넥터(Connectors)를 누릅니다.
  2. + 추가(Add) → 커스텀 커넥터 추가(Add custom connector)를 누릅니다.
  3. 이름 칸에 MyJai, 주소 칸에 연결 방법 안의 주소를 복사 → 붙여 넣기 하고 계속을 누릅니다. 인증은 지금 로그인, OAuth 클라이언트는 자동 등록을 고르고 추가.
  4. 자비아 로그인 창이 뜨면 자비아 아이디·비밀번호로 로그인합니다. 「연결됨」이 보이면 끝입니다.

「인증받지 않은 커넥터」라는 안내가 보일 수 있는데, 자비아가 직접 만든 커넥터라서 나오는 문구입니다. 그대로 진행하시면 됩니다.

Claude 화면이 바뀌어 메뉴 이름이 조금 다를 수 있습니다(예: 「플러그인」 또는 설정 → 커넥터). 「커넥터」를 찾으면 됩니다.

3-2. 휴대폰에서 쓰기 — 3단계
  1. 앱스토어·플레이스토어에서 Claude 앱을 설치하고, PC 와 같은 계정으로 로그인합니다.
  2. 입력창 왼쪽 ＋ → 커넥터에서 MyJai 가 켜져 있는지 확인합니다(꺼져 있으면 켜 주세요).
  3. MyJai 홈의 「Claude 열고 오늘 브리핑 받기」나 질문 버튼을 누르면 Claude 앱이 열립니다. 채워진 글 그대로 ↑ 보내기를 누르세요.

입력창의 마이크를 누르면 말로 맡길 수 있습니다. 휴대폰에서 MyJai 가 보이지 않으면 PC 에서 연결(3-1)부터 해 주세요.

4. 권한 설정 — 이렇게 해 두면 편해요

연결 후 커넥터를 누르면 도구마다 권한을 고를 수 있습니다.

  • 모든 도구를 「항상 허용」으로 두세요. 발송·저장·등록 같은 실행은 MyJai 가 먼저 미리보기를 보여 주고 회원님이 OK 해야만 실행되므로 안전합니다.
  • 「차단」은 고르지 마세요. 링크 만들기·저장 같은 기능이 「권한 설정에서 막혔습니다」라며 멈춥니다(PC·휴대폰 결과가 달라지는 가장 흔한 이유).
  • PC 에서 바꾸면 휴대폰에도 같이 적용됩니다: Claude 설정 → 커넥터 → MyJai.
  • 브리핑 카드의 버튼(예: 「📞 오늘 전화할 3명」)을 누르면 Claude 가 「MyJai 커넥터가 메시지를 보내려고 합니다」 확인 창을 띄웁니다. 「한 번 허용」을 누르면 질문이 채팅으로 들어갑니다.
  • 더 정확하게 쓰려면: Claude 설정 → 일반의 개인 선호(Personal preferences) 칸에 이 한 줄을 넣어 두세요. 고객·보험·세금·계산·자비아 자료 질문은 MyJai 커넥터를 먼저 쓴다 「MyJai」라고 말하지 않아도 자비아 계산기·자료를 먼저 쓰게 됩니다(질문 버튼은 앞에 「MyJai,」가 자동으로 붙습니다).
5. 물어보는 법 — 평소 말하듯이
  • 문장으로 편하게 말하면 됩니다. 연금에 관심 있는 고객 누구야?
  • 고객은 이름으로 말하세요. 박철수 고객 요약해줘
  • 자비아와 상관없는 일반 질문과 헷갈리면 앞에 「자비아」나 「MyJai」를 붙이세요. 자비아 계산기로 증여세 계산해줘
  • 한 번에 이어서 시켜도 됩니다. 새 상담 요청 보여주고, 첫 번째 건은 연락 중으로 바꿔줘
  • 휴대폰 앱에서는 입력창의 마이크를 누르고 말로 해도 됩니다.
6. 보내기·저장 전에는 꼭 「OK」 — 미리보기

알림톡 발송, 예약, 고객 등록, 메모, 업무일지 기록, 상태 변경처럼 자비아에 무언가를 바꾸는 일은 바로 실행되지 않습니다.

  1. 먼저 미리보기(누구에게·무엇을·비용)를 보여 줍니다.
  2. 맞으면 OK 또는 보내줘 라고 답하세요. 그때 실행됩니다.
  3. 바꾸고 싶으면 시간을 9시로 바꿔줘처럼 말하면 새 미리보기를 다시 보여 줍니다.

미리보기는 10분이 지나면 사라집니다. 그때는 다시 부탁하면 됩니다.

7. AI 가 정리하고, 자비아는 저장·발송만

증권 사진·약관 PDF·기업 재무 리포트 같은 자료는 회원님의 AI 가 직접 읽고 정리합니다.

  • 보험 증권 캡처: 대화창에 사진을 올리고 정리해서 이영희 고객 메모로 남겨줘
  • 기업 재무분석 PDF: 올린 뒤 요약해서 제안서AI에 넣을 글로 이지메모에 담아줘 → 이지메모에서 복사해 제안서AI 에 붙여 넣기
  • 보험 약관: 한화생명 약관 어디서 받아? → 공시실 링크에서 PDF 를 받아 대화창에 올리고 이 약관에서 면책 조항 정리해줘
  • 금액 계산은 반드시 자비아 계산기로 합니다. 자비아 계산기에 없는 계산을 AI 가 하면 「참고용 추정」이라고 표시합니다.
8. 비용과 개인정보
  • 고객에게 알림톡을 보낼 때만 지금처럼 건당 20원이 포인트(없으면 잔액)에서 차감됩니다. 미리보기에 비용이 먼저 나옵니다.
  • Claude 무료 사용량이 다 되면 잠시 뒤 다시 쓸 수 있습니다. Claude 유료 요금제를 쓰시면 넉넉히 쓸 수 있습니다.
  • 고객 전화번호는 AI 에게 절대 전달되지 않습니다(가린 번호만). 전화는 자비아 화면에서 거세요.
9. 잘 안 될 때
  • 새 기능이 안 보여요 → PC Claude 의 커넥터 메뉴(…)에서 도구 목록 새로고침을 누르세요. 휴대폰은 PC 에서 새로고침하면 따라 바뀝니다. 그래도 그대로면 PC 에서 연결 해제 후 다시 연결하세요.
  • 「계산기가 없다」고 해요 → 자비아 계산기 목록 보여줘 라고 먼저 물어보세요.
  • 자료 내용을 모른다고 해요 → 자비아에서 읽어서 알려줘 라고 한 번 더 말하세요.
  • 로그인 창이 다시 떠요 → 자비아 아이디로 다시 로그인하면 됩니다(보안상 가끔 다시 묻습니다).
  • 처음에 붉은 안내가 떠요 → 링크로 글이 채워진 채 열릴 때 Claude 가 띄우는 기본 안전 문구입니다. 자비아가 끌 수는 없고, 그대로 ↑ 보내기를 누르면 됩니다.
  • 「자비아에서 보기」가 로그인 화면으로 열려요 → 카드 안의 「자비아에서 보기」 버튼은 로그인된 채로 열립니다(누를 때마다 2분짜리 1회용 열쇠). AI 가 글 속에 적은 주소는 회원님이 자비아에 로그인한 브라우저에서 열어 주세요. 휴대폰은 같은 종류 기기 1대 규칙에 따라 다른 휴대폰 화면이 로그아웃될 수 있습니다.
  • 권한 설정에서 막혔다고 나와요 → 4번처럼 MyJai 도구를 「항상 허용」으로 바꿔 주세요.
  • 답이 막혔어요(사용량 초과) → 무료 사용량이 끝난 것입니다. 시간이 지나면 다시 됩니다.
  • 그 밖에는 자비아 고객센터(카카오톡 채널)로 문의해 주세요.
10. 새로 생긴 일 — 오늘의 자비아 · 카톡 묶음 · AI 보관함
  • 오늘의 자비아: 오늘의 자비아 요약해줘 → 오늘 나온 자료를 한 줄씩 요약하고, 안 본 것·맞춤 ★ 을 표시합니다. 이어서 이 중에 법인 대표한테 보낼 만한 거 골라줘 하면 됩니다.
  • 카톡 묶음: 연금 관심 고객들한테 오늘 리포트 카톡 묶음 만들어줘 → 고객마다 문구+링크와 「복사」 버튼이 나옵니다. 복사하면 업무일지에 「카톡 · 링크 전달」이 저절로 남습니다(하루 한 번).
  • 새 고객 링크: 오늘의 영업주제 고객 화면(오늘의 이야기 링크), 이너서클 대표 전용 CEO 브리핑 링크, 아침독서 링크.
  • AI 보관함: AI 가 정리한 분석·제안 초안을 자비아에 저장해줘 → 미리보기 → OK. 고객 상세와 이 화면 「최근 AI 기록」에서 다시 볼 수 있고, 1년 뒤 자동으로 지워집니다. 전화번호·주민번호 모양은 가려서 저장됩니다.
  • 고객 공유 페이지: 이 글 고객용 페이지로 만들어줘 → 고객이 읽을 화면(90일)과 상담 신청·전화 버튼이 생깁니다. 회사·플랫폼 이름은 들어가지 않고, 고객 실명 대신 「고객님」을 권합니다. 필요 없으면 공유 꺼줘.
