기업 재무제표 PDF를 넣으면 1분 안에 — 대표님께 카톡으로 보낼 CEO 숫자 리포트(앞면)와 컨설턴트 전용 화법 카드(뒷면)가 만들어집니다.

핵심 기능 Highlights
1

재무제표 PDF → 1분 완성

CRETOP·KODATA·NICE 기업분석보고서 PDF를 첨부하면 회사명·대표·지분·재무 수치를 자동으로 읽어, 대표님께 바로 보낼 수 있는 1장 리포트를 만들어 드립니다. 타이핑할 것은 연락처 정도뿐입니다.

2

숫자는 계산기, 문장만 AI

주식 평가(상증령 제54조 가중평균)와 예상 상속세는 검증된 계산 모듈이 산출하고, 회계 항등식 검산까지 통과한 숫자만 문서에 실립니다. AI는 그 숫자를 설명하는 문장만 씁니다 — 임의로 숫자를 만들지 못합니다.

3

진단 엔진이 헤드라인을 고름

재무 시그널 17종을 판독해 그 회사에 가장 강한 이야기(성장의 역설 · 가치 정점 · 승계 시계 · 이익 누수 등 8가지 패턴)를 자동 선정합니다. 어느 회사든 "그 회사만의 첫 문장"으로 시작합니다.

4

관계 3단계 맞춤 톤

처음 접근 · 접점 있음 · 기존 고객 — 대표님과의 관계를 고르면 도입 문장, 공개 수위, 연락 문턱(10분 통화/30분 미팅/정기 미팅)이 전부 달라집니다. 문서 유형도 프라이빗 뱅킹 서한(A)과 관인 문서(C) 중 선택합니다.

5

뒷면 화법 카드까지 한 세트

리포트만 주지 않습니다. 첫 통화 30초 오프닝, 예상 거절 3가지와 대응 멘트, 구두 클로징, 발송 전 체크리스트가 담긴 컨설턴트 전용 카드가 함께 생성됩니다 — CEO 발송 파일에는 절대 포함되지 않습니다.

6

서버에 아무것도 남지 않음

재무제표 PDF는 브라우저 안에서만 처리되고, 완성 리포트는 회원님 컴퓨터에 파일로만 저장됩니다(앞면 HTML + 화법카드 + 카톡 표지 이미지 3종). 고객사 정보가 서버 어디에도 보관되지 않습니다.

이용 순서 How it works
1

제안서AI에서 「📊 CEO리포트」 카드 클릭

jarvia.co.kr 로그인 → 제안서AI 진입 → 다섯 번째 카드를 누르면 전용 화면이 열립니다.

2

문서 유형과 관계 선택

A안(프라이빗 뱅킹 서한)·C안(관인 문서) 중 하나를 고르고 — 미리보기로 실물을 먼저 볼 수 있습니다 — 대표님과의 관계 3단계 중 하나를 반드시 선택한 뒤 [새로 만들기] — 관계를 고르지 않으면 진행되지 않습니다(문서의 톤·연락 문턱이 달라지기 때문).

3

재무제표 넣기 — PDF 또는 직접 입력

CRETOP·KODATA·NICE PDF를 넣으면 수치 추출 → 회계 검산 → 주식평가·상속세 계산이 끝나고, 회사명·대표명이 자동으로 채워집니다(빈 칸일 때만 — 내가 쓴 값은 덮지 않음). ⚠ 반드시 텍스트형 PDF만 읽을 수 있고, 스캔·이미지 저장본이거나 PDF가 없으면 📝 숫자 직접 입력으로 동일하게 진행합니다. 자세한 방법은 아래 「재무 데이터 넣기」 참고.

4

기본 정보 보완

대표 연령·근속·연봉, 가족 메모(선택), 배당·최대주주 여부, 회원님 휴대전화와 응대 시간을 입력합니다. 타이핑하는 즉시 우측 리포트에 실시간 반영됩니다. 확인이 필요한 항목(최대주주 여부 등)은 경고로 안내됩니다.

5

[리포트 생성] — 20~30초

진단 엔진이 즉시 헤드라인 패턴을 정하고 숫자·근거·봉인 항목이 먼저 그려진 뒤, AI가 문장을 채웁니다. 기다리는 동안에도 골격을 볼 수 있습니다.

6

저장하고 이용 시작

생성이 끝나면 저장 안내가 뜹니다. 저장해야 이용이 확정되며(요금은 아래 이용 안내 참고), 저장 시 3개 파일 — 앞면 리포트 HTML · 화법카드 HTML · 카톡 표지 이미지 — 이 컴퓨터로 내려받아집니다.

7

문장 다듬기

리포트 본문(점선 표시)을 클릭해 그 자리에서 바로 고칠 수 있고, 헤드라인·인사·소개 문단·안심 문구·클로징 4개 문단은 [↻ 다시 쓰기]로 다른 문장을 받아볼 수 있습니다(리포트당 20회 · 추가 비용 없음). 숫자·법령 근거·면책 문구는 보호를 위해 잠겨 있습니다. 자세한 사용법은 아래 「다듬기」 참고.

8

카톡 발송 — 3단계 순서

① 표지 이미지 → ② 리포트 HTML 파일 → ③ 화법카드의 오프닝 멘트 복사 순서로 보내면 수신 화면이 가장 좋습니다. 리포트의 통화 버튼을 대표님이 누르면 회원님 휴대전화로 바로 연결됩니다.

9

다음 날 확인 전화 + 수정은 파일로

발송 다음 날 오전 확인 전화가 마무리 기본기입니다. 수정이 필요하면 저장했던 HTML 파일을 [저장한 리포트 열기]에 넣으세요 — 숫자·문장·설정이 그대로 복원됩니다.

⚠ 반드시 텍스트형 PDF만 첨부하세요

스캔·촬영·이미지로 저장된 PDF는 글자를 읽을 수 없습니다. 이미지 PDF를 첨부하면 안내와 함께 📝 숫자 직접 입력이 자동으로 열립니다 — 화면에 보이는 숫자 7개만 옮겨 적으면 동일하게 생성됩니다. 파일은 서버로 전송되지 않고 브라우저 안에서만 처리됩니다.

A

길 A — 크레탑 PDF 첨부 (가장 정확)

CRETOP·KODATA·NICE 기업분석보고서, 크레탑 웹출력 「기업 종합 보고서」까지 인식합니다. 첨부하면 숫자를 자동 추출하고 회계 항등식(자산=부채+자본 등)으로 검산합니다 — 검산 통과 배지가 뜨면 그 숫자는 믿어도 됩니다.

PDF가 못 읽은 항목이 있으면 노란 안내가 항목명과 함께 뜹니다(예: "대표 지분율 · 총발행주식수 — 보충하면 상속세 산출이 정확해집니다") → [보충 입력 열기]를 누르면 빈 칸만 노란색으로 표시된 입력창이 열립니다.

검산 통과분만 리포트에 실립니다
B

길 B — 📝 숫자 직접 입력 (PDF가 없거나 이미지일 때)

단위는 원(₩)입니다. 숫자를 입력하면 칸 아래에 억·만 환산이 실시간으로 표시됩니다 — 예: 1,657,368,000 → "= 16억 5,736만원". 자릿수를 헤아릴 필요가 없고, 잘못 넣으면 환산이 이상하게 떠서 그 자리에서 눈에 띕니다.

  • 크레탑 표가 백만원 단위면 뒤에 0을 여섯 개(1,657 → 1,657,000,000), 천원 단위면 0을 세 개 붙이세요.
  • 필수 7칸: 자산총계 · 부채총계 · 자본총계 · 자본금 · 매출액 · 영업이익 · 당기순이익 — 이게 있어야 생성됩니다.
  • 권장 칸(접점 정확도): 이익잉여금 · 현금 · 총차입금 · 이자비용 · 가지급금(없으면 0) · 영업현금흐름 · 매출채권 당기/전기 · 지분율 · 3개년 손익 · 총주식수. 모르는 칸은 비워 두세요.
  • 자산 = 부채 + 자본 검산을 통과해야만 [적용]이 눌립니다. 불일치하면 차액이 억·만으로 표시되며 차단 — 오타가 대표님 앞까지 가는 길이 없습니다.
  • 숫자 칸은 콤마 자동, 문자 입력 불가, 폰에서는 숫자 키패드가 뜹니다.
B+

같은 창으로 — 파싱값 보충·교정

PDF 파싱 후 직접 입력을 열면 파싱값이 미리 채워져 있고 못 읽은 칸만 노란색입니다. 노란 칸만 채우거나(예: 지분율 + 총발행주식수 → 상속세 잠금 해제) 틀린 값을 고친 뒤 [✔ 수정한 값 반영] — 수정한 칸만 반영되고 3개년 등 나머지 파싱 데이터는 보존됩니다.

  • 아무것도 안 고쳤으면 버튼이 회색(꺼짐) — 고장이 아니라 "누를 이유가 없다"는 뜻입니다. 그냥 진행하세요.
  • 우선순위 원칙: 내가 마지막에 입력·적용한 값 > 파싱값 > 자동채움(빈 칸만). 사용자 입력이 항상 이깁니다.

재무 신호로 찾은 접점 — 문서 전체의 축

재무 수치를 규칙 기반 신호(차입 의존, 이익잉여금 과다, 이익-현금 괴리, 지분 집중 등)로 판독해 상위 접점 3개를 실제 회사 숫자 근거와 함께 보여줍니다. 하나를 고르면 헤드라인·숫자·화법이 전부 그 축으로 쓰입니다.

  • 부분 신호 배지 = 요구 신호 일부만 충족한 후보라는 정직한 표시. 완전 충족 패턴보다 점수가 항상 낮습니다.
  • 신호가 하나도 없으면(재무가 깨끗) 생성이 중단됩니다 — 억지 접점을 지어내지 않습니다.

  • 각 문단의 위치는 우측 리포트의 금색 이름표로 표시됩니다 — 이름표는 화면 표시용이라 저장·인쇄·카톡 이미지에는 절대 나가지 않습니다.
  • 한도: 리포트당 20회 (추가 비용 없음).

저장 = 이용 확정 + 파일 3건

저장 시 요금 확정(또는 무료 횟수 사용)과 함께 ① 앞면 리포트 HTML ② 화법카드 HTML ③ 카톡 표지 PNG가 내려받아집니다. 브라우저가 "여러 파일 다운로드 허용"을 물으면 허용을 누르세요. 파일명은 바꾸지 말고 보관하세요.

💬

카톡 발송 — 앞면만, 3단계 순서

① 표지 이미지 → ② 앞면 리포트 HTML → ③ 화법카드의 오프닝 멘트를 복사해서(파일 아님!) 보내는 순서가 수신 화면이 가장 좋습니다. 리포트의 통화 버튼을 대표님이 누르면 회원님 휴대전화로 바로 연결됩니다. 모바일에서 열어도 중앙 정렬로 깔끔하게 보입니다.

🖨

인쇄 — A4 자동 조판

앞면·화법카드 모두 A4 세로 규격으로 자동 조판되어 블록이 페이지 경계에서 잘리지 않습니다. 화법카드는 인쇄 시 밝은 인쇄용 배색으로 자동 전환됩니다.

자주 묻는 질문 FAQ
📄"PDF를 읽을 수 없습니다"라고 나와요▼
스캔·촬영·이미지로 저장된 PDF입니다. 자동으로 열린 📝 숫자 직접 입력에 화면의 숫자 7개만 옮겨 적으면 동일하게 생성됩니다. 또는 크레탑에서 텍스트형 PDF로 다시 내려받으세요.
🔒상속세가 잠겨 있어요▼
대표 지분율과 총발행주식수가 미확인 상태입니다. 직접 입력에서 두 칸을 채우고 [수정한 값 반영]을 누르면 즉시 산출됩니다. 잠긴 채 보내는 것도 전략이 됩니다 — 문서의 "지분율 확인 즉시 산출됩니다" 문구가 만남의 명분이 됩니다.
🔘[수정한 값 반영] 버튼이 안 눌려요▼
정상입니다. 파싱값 그대로면 누를 이유가 없어 꺼져 있습니다. 값을 하나라도 고치거나 노란 칸을 채우는 순간 버튼이 켜집니다.
✍숫자를 바꿨는데 문장이 그대로예요▼
숫자·상속세는 이미 반영됐습니다. AI 문장은 생성 시점 기준이라 [다시 생성]을 눌러야 문장에도 새 숫자가 들어갑니다.
🌀수정했는데 화면이 예전 그대로예요▼
브라우저 캐시일 가능성이 큽니다. Ctrl+F5(강력 새로고침) 또는 시크릿 창에서 다시 열어 보세요.
📁저장 파일이 여러 개인데 뭘 보내나요▼
대표님께는 표지 PNG + 앞면 리포트 HTML만 보냅니다. 화법카드 HTML과 브리핑은 컨설턴트 전용 — 절대 발송하지 마세요.
