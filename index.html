신규

'기업맞춤형 정부지원사업조회' 사이트 오픈

고객 기업에 맞는 정부·지자체 지원사업을 30초 만에 찾아, 연락할 명분을 만들어 드리는 도구입니다. 지원사업 공고 1,500여 건이 매일 아침 6시 자동 수집되고, 마감 지난 공고는 자동으로 사라집니다.

1. 들어가는 방법

  • 메인 하단의 [정부지원사업조회] 버튼 클릭
  • 고객기업을 저장해 두면, 메인 상단에 "기업 맞춤 공고 — 신규 N건" 알림이 자동으로 뜹니다 → 클릭하면 그 기업 조건으로 바로 열립니다

2. 기본 사용법 — 아는 만큼만 입력

  • 지역·기업규모·업종을 고르면 자격 안 되는 공고가 즉시 빠집니다
  • 표준산업분류(KSIC): 코드를 몰라도 [이름으로 검색]에 "로봇", "화장품"처럼 단어만 치면 자동 입력. 끝까지 안 골라도 됩니다
  • 설립연도를 넣으면 업력이 자동 계산되어 "창업 7년 이내" 같은 공고를 정확히 거릅니다
  • 직원수: 인원 요건 미달 공고 제외
  • 보유 인증: 여성·사회적·장애인기업은 체크해야 전용 공고가 보입니다 — 고객이 가진 인증은 빠짐없이 체크하세요

3. 결과 읽는 법

  • 핵심 일치 = 지역·업종이 진짜 맞는 공고만 추린 숫자 (화면 목록)
  • ★ = 이 기업 업종에 맞는 공고 — 항상 최상단. 영업 멘트 1순위!
  • NEW = 최근 7일 신규 / D-7·오늘 마감·상시 = 마감까지 남은 날
  • 제목 클릭 = 기업마당 공고 원문이 새 탭으로
  • 맨 아래 [기타 지원가능 공고 펼치기] = 전국 누구나 가능한 일반 사업

4. 기간으로 거르기

  • 신규(오늘/금주/당월) · 마감(금주/당월/익월) 칩 — 누르면 켜지고 다시 누르면 해제
  • 둘을 같이 켜면 "이번 주에 떴는데 이달 마감인 긴급 건"만 골라집니다

5. 고객기업 저장 — 한 번 입력하면 끝

  • 조건 입력 후 [💾 고객기업으로 저장] → 상단 칩으로 등록 (최대 100개)
  • 칩 클릭=조회 · ✏️=조건 수정 · ✕=삭제
  • PC에서 저장하면 폰에서도 그대로 — 같은 계정이면 자동 동기화
  • 저장해 두면 맞는 신규 공고가 뜰 때마다 메인에서 자동 알림

6. 영업 활용 루틴

  • 아침: 메인 알림 확인 → "대표님, 오늘 ○○ 지원사업이 새로 나왔는데 딱 대상입니다" 카톡
  • 미팅 전: 고객 칩 클릭 → ★ 공고 2~3개 메모해서 화두로
  • 금요일: [마감 금주] 켜고 긴급 연락 명분 찾기
💡 법인 고객 미팅 전 30초 — ★ 표시 공고 2~3개면 대화의 문이 열립니다.

7. 꼭 알아두세요

  • 매칭은 1차 선별입니다 — 신청 전 반드시 제목을 클릭해 원문의 세부 자격을 확인하세요
  • 데이터 출처는 정부 공식 포털 기업마당(bizinfo.go.kr)
  • 다른 지역 전용 공고가 안 보이는 건 정상입니다 (전국 사업은 '기타'에)
  • 결과가 0건이면 조건이 너무 좁은 것 — 직원수나 KSIC 세세분류를 비워보세요
