📊 상속세 완전 계산기 사용 가이드

환영합니다! 이 계산기는 2026년 5월 5일 기준 현행 세법의 주요 공제·할증 항목을 정밀 반영한 완전판입니다.

✨ 완전판의 핵심 기능

  • ✅ 상속세 및 증여세법에 따른 정확한 계산 (현행 법령 기준)
  • ✅ 일괄공제 5억 vs 기초공제 2억 + 인적공제 자동 비교
  • ✅ 배우자공제 정밀 산정 (최소 5억 ~ 최대 30억, §19 단서 적용)
  • ✅ 동거주택상속공제 (최대 6억원), 영농상속공제 30억, 가업상속공제 (300~600억 3구간)
  • ✅ 비상장주식 별도 입력 + 최대주주 20% 할증 (평가단계에서 정확히 적용)
  • ✅ 세대생략 할증 비율 정밀 적용 (미성년 20억 초과 시 40%)
  • ✅ 대습상속 예외 (자녀 사망으로 손자녀 상속 시 할증 제외, §27 단서)
  • ✅ 사전증여 합산 (상속인 10년 / 비상속인 5년) + 기납부 증여세 공제
  • ✅ 비상속인 유증 공제한도 정밀 반영 (§24)
  • ✅ 신고세액공제 3% (2019년 이후 §69)
  • ✅ 장례비 의제공제 500만원 자동 적용 (시행령 §9②)

💡 입력 순서 (6단계)

  • 1단계: 상속개시일자 (달력 선택) 및 상속인 정보 (배우자/자녀/미성년·연로·장애인)
  • 2단계: 상속재산 입력 — 부동산, 금융재산, 기타재산, 비상장주식(별도), 퇴직금/보험금
  • 3단계: 사전증여 입력 — 배우자/기타 사전증여 + 기납부 증여세 + 비상속인 유증
  • 4단계: 채무·공과금·장례비 입력
  • 5단계: 특수 공제 — 동거주택·가업상속·영농상속·재해손실
  • 6단계: 할증 항목 확인 — 최대주주 할증, 세대생략(대습상속 예외 체크)

⚠️ 입력 시 주의사항

  • 상속개시일자는 달력 아이콘을 클릭하여 정확히 선택 (1900~2100년)
  • 모든 금액은 원화(₩) 기준 (천단위 콤마 자동 표시)
  • 비상장주식은 기타재산이 아니라 별도 입력란에 입력 (최대주주 할증 정확 적용)
  • 사전증여재산: 상속인은 10년 이내, 비상속인은 5년 이내 증여분만 입력
  • 비상속인 유증·사인증여: 위 상속재산에 이미 포함된 금액 중 친구·법인 등에게 유증한 부분만 분리 입력 (공제한도 산정 시 차감)
  • 대습상속: 자녀가 먼저 사망하여 손자녀가 상속받는 경우 세대생략 할증 제외 (체크박스 선택)
  • 장례비 500만원 미만 입력 시 시행령에 따라 500만원 의제공제 자동 적용

📜 법령 기준일 및 개정 추진 안내

  • 본 계산기는 2026년 5월 5일 기준 현행 상속세 및 증여세법을 반영합니다.
  • 2024년 7월 정부 세법개정안의 자녀공제 5천만원 → 5억 상향, 최고세율 50% → 40% 인하, 최대주주 할증 폐지는 2024년 12월 국회에서 부결되어 미반영(현행 유지)입니다. (2025년 입법예고된 유산취득세 전환안은 국회 통과 시 2028년 시행 예정이며 아직 미확정)
  • 가업상속공제·영농상속공제 적용 시 사후관리 5년 요건 별도 검토 필요.

※ 본 계산기는 참고용 시뮬레이션이며, 실제 신고는 반드시 세무사 등 전문가와 상담하시기 바랍니다.
