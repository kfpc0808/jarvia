3. 이월결손금 공제 한도

법인 구분공제 한도
중소기업소득금액의 100%
일반법인/대기업소득금액의 80%

4. 사용 순서

  • 법인 구분 선택 (중소/중견/일반/대기업)
  • 회계상 당기순이익 입력
  • 세무조정 가감 입력 (손금불산입 +, 익금불산입 -)
  • 이월결손금 있으면 입력 (한도 자동 계산)
  • 세액공제/감면 입력 → 최저한세 자동 검증
  • 결과 확인 및 상담 결과 복사

5. 주의사항

  • 본 계산기는 시뮬레이션 목적이며, 정확한 세액은 세무신고 시 확정됩니다.
  • 토지등양도소득, 미환류소득, 가산세 등은 별도 계산이 필요합니다.
  • 농어촌특별세는 세액감면 적용 시 감면세액의 20%가 부과됩니다.
  • 중간예납세액은 기납부세액에 입력하여 차감합니다.
