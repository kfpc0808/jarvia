    🚀
    시작하기
    자료 생성
    1시작 화면에서 분야(연금·보험·자산·기업)를 고르고, 고객 정보를 자연스럽게 적으면 자료가 생성됩니다.
    2진행자가 국민연금·필요자금 기준·퇴직/개인연금·주택연금을 차례로 물어요. 답하면 더 정확해집니다(모르면 “미반영”).
    ✍️
    직접 편집
    무료
    ·슬라이드의 글자를 클릭하면 바로 편집 — 정렬·크기·색상·형광펜 툴바가 떠요.
    ·본문 아래 ＋ 텍스트 행으로 원하는 만큼 줄을 추가하고, 각 행을 좌·중·우(⬅ ☰ ➡)로 정렬.
    ·행마다 ↑ ↓ 이동, ✕ 삭제 가능.
    🖼️
    이미지
    무료
    ·＋ 이미지 버튼으로 넣거나, Ctrl+V로 클립보드 이미지를 바로 붙여넣기.
    ·이미지를 마우스로 끌어 원하는 위치로 이동.
    ·모서리·변의 8개 손잡이로 좌우상하 자유롭게 크기 조절.
    📑
    슬라이드 관리
    무료
    ·슬라이드에 마우스를 올리면 ↑ ↓ ⤒ ⤓ 버튼 — 위/아래·맨앞/맨뒤로 위치 이동. 페이지 번호는 자동으로 다시 매겨집니다.
    ·채팅에 “빈 슬라이드 추가”·“5번 위치에 빈 페이지”라고 하면 빈 슬라이드를 직접 채울 수 있어요(무료).
    🤖
    진행자(AI)에게 시키기
    비용
    ·“3번 보강해줘”·“○○ 슬라이드 추가”처럼 지시하면, 진행자가 “이렇게 할까요?”로 확인 후 만들어요(헛생성 방지).
    ·AI 수정·생성은 비용이 들어요. 글자·정렬·이미지처럼 직접 할 수 있는 건 직접 하는 게 가장 경제적입니다.
    🎚️
    라이브 시뮬레이터
    무료
    ·채팅에 “시뮬레이터”라고 하면 확인 후 추가 — 슬라이드에서 슬라이더로 은퇴나이·생활비·수익률을 바꾸면 결과가 즉시 재계산. 추가 비용 없이 직접 조정.
